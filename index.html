A personal health vault

Three open-source tools that bring a family's health data into one place that the family owns: a Medplum FHIR R4 server, readable by AI health-advisor agents.

iPhone ─ encrypted ─▶ relay ─┐
Garmin ─ official API ───────┼─▶ FHIR R4 ─▶ Medplum ─▶ agents
Paper  ─ scan · review ──────┘
  • healthkit-archive — end-to-end encrypted backup of Apple Health. The phone encrypts with age and signs with the Secure Enclave; the Cloudflare relay only ever sees ciphertext.
  • garmin-archive — backs up Garmin Connect via the official API to Google Drive and S3 Glacier. Self-healing, polite to the API, standard library only.
  • paper-archive — paper lab reports, ECGs, scans and vaccination slips into FHIR. An agent transcribes; deterministic code validates and maps; a person approves. The agent never writes FHIR.

Python · Swift · Cloudflare Workers · FHIR R4
